لعبة شطرنج كاملة بثلاث أوضاع لعب

---

## 📁 ملفات المشروع

```
chess/
├── index.html      ← الموقع كامل (الواجهة + محرك الشطرنج)
├── server.js       ← سيرفر الأونلاين (Node.js + WebSocket)
├── sw.js           ← Service Worker (تشغيل أوفلاين)
├── manifest.json   ← PWA Manifest
├── icon.svg        ← أيقونة التطبيق
└── package.json    ← تبعيات Node.js
```

---

## 🚀 طريقة التشغيل

### الطريقة 1 — بدون سيرفر (أوفلاين فقط)
افتح `index.html` مباشرة في المتصفح.
- ✅ ضد البوت يشتغل عادي
- ✅ لاعبَان يشتغل عادي
- ❌ الأونلاين لا يعمل بدون سيرفر

---

### الطريقة 2 — مع سيرفر (كل الأوضاع شغّالة)

#### المتطلبات
- Node.js مثبّت على جهازك
- [تحميل Node.js](https://nodejs.org)

#### خطوات التشغيل

```bash
# 1. افتح CMD أو Terminal جوا فولدر chess
cd chess

# 2. ثبّت المكتبات
npm install

# 3. شغّل السيرفر
node server.js
```

#### بعد التشغيل
افتح المتصفح على:
```
http://localhost:3000
```

## 🎮 أوضاع اللعب

| الوضع | الوصف | يحتاج إنترنت؟ |
|-------|-------|----------------|
| 🌐 أونلاين | ألعب مع صديق عبر غرفة | ✅ نعم (مع السيرفر) |
| 🤖 ضد البوت | 3 مستويات (سهل/متوسط/صعب) | ❌ لا |
| 👥 لاعبَان | على نفس الشاشة | ❌ لا |

---

## 🌐 كيف يشتغل الأونلاين؟

1. اللاعب الأول يضغط **"إنشاء غرفة"** → يظهر كود من 4 حروف
2. يشارك الكود مع صديقه
3. الصديق يضغط **"الانضمام"** ويكتب الكود
4. اللعبة تبدأ تلقائياً!

---

## 📱 إضافة للشاشة الرئيسية (PWA)

### على الجوال (iOS/Android):
- افتح الموقع في المتصفح
- اضغط **مشاركة** (iOS) أو **قائمة** (Android)
- اختر **"إضافة للشاشة الرئيسية"**
- الموقع هيشتغل كتطبيق كامل بدون إنترنت!

## 🔧 نشر على الإنترنت

لو عايز الأونلاين يشتغل مع أي شخص في العالم:

### Railway (مجاني):
```bash
# 1. حمّل Railway CLI أو استخدم الموقع
# 2. اعمل حساب على railway.app
# 3. ارفع المشروع
# 4. غيّر WS_URL في index.html
```

### Render (مجاني):
1. ارفع المشروع على GitHub
2. اربطه بـ Render.com
3. غيّر `WS_URL` في `index.html` بالـ URL الجديد
